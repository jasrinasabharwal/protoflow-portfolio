# Builder's Log — ProtoFlow Portfolio

A responsive React + Vite portfolio with a custom editorial / engineering-notebook visual style.

## Run locally

1. Install Node.js (LTS) from https://nodejs.org/
2. Extract this folder.
3. Open a terminal in this folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite.

## Before sharing it with ProtoFlow

Search the project for `YOUR_EMAIL@example.com` and replace it with a professional email address. Also update:
- The browser title and page description in `index.html`
- The visible name/monogram in the header if you want your full name shown
- The email link in `src/main.jsx`
- Any project descriptions that need a more exact title or role
- Add genuine project photos/screenshots and links where possible; the illustrations are custom CSS/SVG artwork, not photos of your actual work.
- If you want a headshot, use an optional professional photo. It is not required.

## Publish it

You can deploy a Vite site through Vercel or Netlify. Connect the folder/repository, use `npm run build` as the build command, and `dist` as the output directory. The website is not online until you deploy it.

- Admissionary is described as ongoing research, not a launched app.
- The page describes PCB design as an area of interest to learn, not an existing area of expertise.
